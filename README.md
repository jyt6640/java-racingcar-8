# 🚗 자동차 경주 게임

---

## 기본 기능 목록

- [X] 주어진 횟수 동안 n대의 자동차는 전진 또는 멈출 수 있다.
- [X] 각 자동차에 이름을 부여할 수 있다. 전진하는 자동차를 출력할 때 자동차 이름을 같이 출력한다.
- [X] 자동차 이름은 쉼표(,)를 기준으로 구분하며 이름은 5자 이하만 가능하다.
- [X] 사용자는 몇 번의 이동을 할 것인지를 입력할 수 있어야 한다.
- [X] 전진하는 조건은 0에서 9 사이에서 무작위 값을 구한 후 무작위 값이 4 이상일 경우이다.
- [X] 자동차 경주 게임을 완료한 후 누가 우승했는지를 알려준다. 우승자는 한 명 이상일 수 있다.
- [X] 우승자가 여러 명일 경우 쉼표(,)를 이용하여 구분한다.
- [X] 사용자가 잘못된 값을 입력할 경우 IllegalArgumentException을 발생시킨 후 애플리케이션은 종료되어야 한다.
- [X] 기본 기능 구현 완료

### 입출력 요구 사항
#### 입력
- 경주할 자동차 이름(이름은 쉼표(,) 기준으로 구분)
```
pobi,woni,jun
```
- 시도할 횟수
```
5
```
#### 출력
- 차수별 실행 결과
```
pobi : --
woni : ----
jun : ---
```
- 단독 우승자 안내 문구
```
최종 우승자 : pobi
```
- 공동 우승자 안내 문구
```
최종 우승자 : pobi, jun
```
- **실행 결과 예시**
```
경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)
pobi,woni,jun
시도할 횟수는 몇 회인가요?
5

실행 결과
pobi : -
woni :
jun : -

pobi : --
woni : -
jun : --

pobi : ---
woni : --
jun : ---

pobi : ----
woni : ---
jun : ----

pobi : -----
woni : ----
jun : -----

최종 우승자 : pobi, jun
```

## 🎯 상세 기능 구현 목록

### ⌨️ 입력
- [X] 사용자로부터 경주할 자동차 이름 입력 받기
    - [X] 자동차 이름 입력 안내 메시지 출력
    - [X] 사용자 입력 받기
    - [ ] 입력값 앞뒤 공백 제거
  

- [X] 사용자로부터 시도할 횟수 입력 받기
    - [X] 시도 횟수 입력 안내 메시지 출력
    - [X] 사용자 입력 받기
    - [X] 입력값 앞뒤 공백 제거

### ⚙️ 로직

#### 입력 검증
##### 자동차 이름 입력 검증
- [X] 자동차 이름은 공백이 아닌지 확인
- [X] 추출 가능한 형식인지 확인


##### 시도 횟수 입력 검증
- [X] 시도 횟수 입력값이 숫자인지 확인
- [X] 시도 횟수가 공백인지 확인
- [X] 시도 횟수가 1 이상인지 확인

#### 추출
##### 자동차 이름 추출
- [X] 쉼표(,)를 기준으로 자동차 이름 분리
- [X] 분리된 각 이름의 앞뒤 공백 제거
- [X] List<String> 형태로 반환


#### 도메인 객체 생성
##### 자동차(Car) 객체 생성
- [X] 자동차 이름이 비었는지 확인
- [X] 자동차 이름이 5자 초과인지 확인
- [X] 검증 통과 시 자동차 이름과 초기 위치를 필드로 저장

##### 일급 컬렉션(Cars) 생성
- [X] 자동차 이름 중복 검사 수행
- [X] Car 객체들을 List으로 관리하는 Cars 일급 컬렉션 생성
 

#### 경주
 - [X] 입력받은 횟수만큼 라운드 반복
 - [X] 각 라운드마다 모든 자동차에 대해 랜덤 값 생성
   - [X] 랜덤 값이 4 이상이면 전진
   - [X] 랜덤 값이 4 미만이면 정지
 - [X] 각 라운드 종류 후 현재 상태 반환

#### 우승자 결정
- [X] Cars에서 모든 자동차의 위치 조회
- [X] 최대 이동 거리를 가진 자동차를 우승자로 선정
- [X] 우승자 이름 반환
- [X] 우승자가 여러 명인 경우 쉼표(,)로 구분

### 🖥️ 출력
- [X] 경주 시작 시
    - [X] 빈 줄 출력
    - [X] "실행 결과" 메시지 출력
- [X] 각 라운드 종료 시
    - [X] 빈 줄 출력 (라운드 구분)
    - [X] 자동차 이름 출력
    - [X] " : " 출력
    - [X] "-"를 현재 위치만큼 반복하여 출력
    - [x] 줄바꿈
- [X] 경주 종료 시
    - [X] "최종 우승자 : " 출력
    - [X] 우승자 이름 출력 (여러 명일 경우 ", "로 구분)

### ⚠️ 예외 처리
##### 입력 검증 단계
###### 공통
- [X] 입력값이 null이거나 빈 문자열일 때 IllegalArgumentException 발생

###### 자동차 이름
- [X] 구분자로 추출 가능한 형식이 아닐 때 IllegalArgumentException 발생

###### 시도 횟수
- [X] 시도 횟수가 숫자가 아닐 때 IllegalArgumentException 발생
- [X] 시도 횟수가 1 미만일 때 IllegalArgumentException 발생

##### 도메인 검증 단계 (Car)
- [X] 자동차 이름이 빈 값일 때 IllegalArgumentException 발생
- [X] 자동차 이름이 공백만 있을 때 IllegalArgumentException 발생
- [X] 자동차 이름이 5자 초과일 때 IllegalArgumentException 발생

##### 컬렉션 검증 단계 (Cars)
- [X] 자동차 이름이 중복될 때 IllegalArgumentException 발생
